# User guide (shop staff)

## Opening the app

1. Double-click **Pakeeza POS** on the desktop.  
2. **Login** with your username and password.  
3. If it is the first time, the manager must **Sign Up** first (owner account).

---

## Taking an order (POS tab)

1. Tap a **category** on the left (e.g. Burgers).  
2. Tap an **item** in the middle.  
3. If a size pops up (Small / Large / etc.), choose one.  
4. Item appears in the **cart** on the right.  
5. Use **+** / **−** to change quantity.  
6. Optional: add a **note** for the kitchen.  
7. Choose payment: **Cash**, **Card**, or **Online**.  
8. Tap **Complete order**.

Receipt printing will be added later — order is saved in the system.

---

## Viewing today’s orders

1. Open **Orders** tab.  
2. See list of today’s bills.  
3. Tap an order for details.  
4. Tap **Refresh** if needed.

---

## Daily report (manager)

1. Open **Reports** tab.  
2. See total sales, order count, cash/card/online split.  
3. See **top items** sold today.  
4. Pull down or reopen tab to refresh.

---

## Settings

- Update **shop name**, address, phones, receipt footer text.  
- **Export backup** — save a copy of all data (do this weekly).  
- **Logout** when your shift ends.

---

## Tips

- Do not run two copies of the app at once.  
- If the app closes unexpectedly, open again and check **Orders**.  
- Tell the manager if an item price on screen is wrong.  
- Printer will be connected in a future update.
